# Version Record launch artwork

Review-only launch artwork generated on 2026-08-08. Nothing in this folder implies publication approval.

## Typography and rendering

- Display: Source Serif 4, weights 400 and 700
- Data labels: IBM Plex Mono, weights 400 and 700
- Headline: “When did that beta ship?” — intentionally platform-neutral
- Palette: cobalt blue, warm cream, release green, and timeline blue
- Fonts are loaded from the licensed files in `src/assets/fonts/`.
- Masters were rendered from HTML/CSS at 2x to 3.2x resolution. Delivery files were reduced from those masters with Lanczos filtering rather than enlarged from smaller images.
